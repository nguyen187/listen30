# Listen 30

Lộ trình 30 ngày luyện nghe tiếng Anh: bài âm nối / âm yếu, chép chính tả có chấm điểm, 300 từ vựng ôn theo lặp lại ngắt quãng, shadowing, nghe số và nghe thả trôi.

- Một file `index.html` tĩnh, không cần server hay build.
- Giọng đọc dùng Web Speech API của trình duyệt (Chrome, Edge, Safari).
- Tiến độ lưu trong `localStorage` của trình duyệt.
